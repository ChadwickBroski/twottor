# Twottor

Twottor is a full web-based social platform inspired by Twitter/X, with an integrated MacaqueAI chat experience.

## Features

- User registration, login, and password reset
- Create and browse posts
- Like and dislike posts
- Trending topics and leaderboard
- User profiles
- Light and dark mode
- MacaqueAI model selection with streamed responses
- Markdown, code blocks, tables, blockquotes, and math rendering in AI responses

## Project structure

```text
index.html          Main application page
login.html          Login page
signup.html         Registration page
forgotpassword.html Password reset page
src/                Application JavaScript modules
assets/             Static assets
style.css           Application styles
firestore.rules     Firestore security rules
```

## Releases

GitHub releases use four-part versioning:

```text
v1.2.2.1
```

- Major version: huge changes or large redesigns
- Medium version: big changes but not too much
- Minor version: small new features
- Patch version: bug fixes
